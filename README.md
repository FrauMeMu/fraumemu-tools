# fraumemu-tools

Eigenständige Browser-Tools für Frau MeMu (Meike Müller). Jede `.html`-Datei läuft direkt im Browser, ruft die Anthropic API mit deinem eigenen API-Key auf (nur lokal in `localStorage` gespeichert) und braucht keinen Server.

- **`fraumemu-content-agent.html`** – Content-Assistent für Instagram-Posts, Reel-Skripte, Story-Slides, Karussells & Hashtags.
- **`fraumemu-sales-stories-generator.html`** – Verkaufsstory-Generator: erzeugt psychologisch aufgebaute, fertig designte Verkaufsstories (Heldenreise, Problem→Lösung, Vorher-Nachher, Gründerinnen-Story, Kundenerfolg, 4P-Formel) für Instagram, E-Mail, Verkaufsseite, Reels oder Story-Slides.
- **`fraumemu-carousel-generator.html`** – Karussell-Generator: erzeugt ein komplettes Instagram-Karussell (Cover, Content-Slides, Closing-Slide, Caption, Hashtags) und rendert es als fertig designte Slide-Karten im Frau-MeMu-Look, die einzeln oder alle auf einmal als PNG gespeichert werden können.

Alle Tools teilen sich denselben gespeicherten API-Key.
